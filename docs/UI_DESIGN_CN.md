# 整合页面设计约束

保留 CPA-Manager-Plus 的现有导航、Card、Button 和主题，不重新设计控制台。新增的整合发行页面沿用原来的 860px 信息列、24px 标题、左对齐定义列表；版本与提交成组展示，不用装饰性仪表盘卡片掩盖兼容信息。

调色沿用上游：白色 #ffffff、浅灰 #f9fafb、文字 #111827、主色 #3b82f6、成功 #22c55e、警告 #f59e0b；实际颜色优先使用主题变量。字体继承上游，不加载外部字体。手机端版本列表变为单列，长 SHA 自动折行，保留键盘焦点与文本状态。

页面只有“检查发行版本”和校验过的整包资源链接；不提供在线执行、单侧安装或覆盖生产的按钮。未配置本产品发行源时明确给出源码流水线路径，不伪造“已是最新版”。
