# 整合页面设计约束

适用版本：`0.4.0`。保留 CPA-Manager-Plus 的现有导航、Card、Button 和主题，不重新设计控制台。版本与提交成组展示，长 SHA 自动折行，不用装饰性图表掩盖兼容信息。

## 视觉与可访问性

沿用上游主题变量，兼容亮色/暗色。参考颜色：白色 #ffffff、浅灰 #f9fafb、文字 #111827、主色 #3b82f6、成功 #22c55e、警告 #f59e0b；实际颜色以主题变量为准。字体继承上游，不加载外部字体。窄屏版本列表转为单列，按钮可换行，保留键盘焦点、可读对比度和文字状态，不仅依靠颜色区分成功/失败。

## 程序更新页

- 默认展示两个上游的当前版本/完整提交、最新正式发布、检查时间、陈旧状态及受控错误。检查失败不显示成“已经最新”。
- 提供检查、单侧更新及一起更新入口；执行按钮仅在管理员授权、`--web-updates --source-updates` 和部署条件均满足时启用，禁用时说明原因。
- 确认目标版本及源码执行信任后才提交；浏览器不能提交本机路径、命令或任意源码 URL。
- 顶部展示升级进度与诊断：当前阶段、总耗时、本阶段耗时、最近真实活动、17 个构建检查阶段完成数。不是下载/耗时百分比，不伪造 ETA 或网络活动。
- 构建结束后继续展示备份、排空、安装、重启、健康检查或恢复状态；页面断线后重连，不以断线推断成功。
- 仅匹配当前程序的成功记录可回滚，必须确认旧版本和数据快照影响；明确不合并快照后的业务写入。
- 原始日志、密钥、环境变量、私有路径和快照内容不进入网页；本机日志由可信操作者管理。

默认源码更新不需要索引/额外发行服务；整包索引是高级兼容模式，不与双上游源码更新混为一谈。实际流程和信任边界见 [SOURCE_UPDATES_CN.md](SOURCE_UPDATES_CN.md)。本次正式源码发行与完整安装包再分发/生产部署签收分别记录。
