# 候选版到正式发行的检查清单

适用版本：`0.4.0-rc.6`（RC）。工程实现项不代表对应全部生产验证已通过；未勾选门禁必须按实际执行记录签收。使用入口见[双上游源码自更新](SOURCE_UPDATES_CN.md)。

## 工程交付

- [x] 原始双上游快照/完整提交、跨平台树摘要、严格适配、构建缓存漂移拒绝。
- [x] 单进程、单对外业务端口、原 Manager 实际页面及核心 SDK。
- [x] 独立/嵌入 Manager 共用 runtime；后台任务/HTTP 排空；关键故障传播。
- [x] 管理员/API/内部管理凭据隔离、内部 Transport 限制与配置热更新边界。
- [x] 产品更新页面/元数据、拒绝原版独立升级路径；独立 Portable 显式授权后支持双上游源码构建、事务安装及成对回滚。
- [x] 备份/恢复/导入、离线检查、升级 dry-run、迁移失败成对回滚；隔离数据演练。
- [x] 单/双侧 stable/edge/pinned 源码更新、隔离验证回执、事务晋级/恢复、互斥构建。
- [x] CI/Compose/Dockerfile、平台包、校验和、SBOM、许可索引、运维文档和有限负载工具。

## 必须依据实际执行记录签收

- [ ] 三平台原生运行矩阵、Linux Full/插件、Docker、race detector 全部达到约定范围。
- [ ] 未打补丁基线也复现的 core HTTP 取消用例失败获得明确处置，时序失败不再被忽略。
- [ ] 真实 OAuth/state/nonce/重放、Claude/Gemini 等范围内供应商与真实认证材料通过授权联调。
- [ ] 用户历史库/认证副本迁移与业务回读；足够历史版本的 schema/加密兼容覆盖。
- [ ] 24h 混合负载、配置热更新、任务恢复、进程重启/长连接/磁盘故障及资源趋势。
- [ ] 同机同版本的可复现性能预算获确认；有限 loopback 诊断不能当作生产 SLO。
- [ ] 全依赖声明/缺失 notice/NOASSERTION 与漏洞风险审核，产品代码许可证决策。
- [ ] 目标产品 Git 身份核对、当前提交全量 CI、可信发行与签名/发布流程；若使用兼容索引模式，另验发行索引（默认源码更新不需要索引）。
- [ ] 运行维护人员确认功能范围：Home/其他 token store/CLI/TUI/pprof/mDNS 等限制。
- [ ] 正式发布审批以及备份/回滚保管、停机与健康检查流程签收。

## 发布安全规则

- 不给上游候选的 npm/Go 测试、PR 工作流提供生产发布凭据。
- 不使用 `pull_request_target` 执行不可信候选；Checkout/Setup/Upload Actions 固定提交。
- 源码晋级回执不等于生产上线审批；手工伪造 JSON 不构成合格验证。
- `release_index.py` 不签名、不上传、不执行二进制；没有真实产品 commit 时拒绝生成“官方”元数据。
- 未通过清单时只允许标记 RC，不替用户发布或安装常驻服务。
