# 发行与生产部署验收清单

适用版本：**`0.4.1` Portable 发行**。GitHub Release 的版本通道不等于全部生产环境准入。源码发布、完整安装包再分发、具体生产部署分别验收；未完成项不得改写为通过。

## 1. 本次发行范围

- 固定发布提交与 `v0.4.1` 标签，GitHub Release 不标记为预发布；不移动 v0.4.0 标签。
- 同提交 master 的 verify 全绿后，手动发行流程原生构建三个 Portable 包（Windows amd64、Linux amd64、Linux arm64），重跑配方/SDK验证、程序与维护 smoke，并逐文件核验后公开。
- 附各包 `.sha256`、`SHA256SUMS` 与脱敏 `release-manifest.json`；不公开运行数据、认证信息、私有目录或原始日志。
- 当前 README、使用/更新文档及程序版本元数据使用 `0.4.1`；未注入构建版本的直接 Go 构建保持 development 身份。
- 发布说明列出已知 CI 问题与验证范围，不声称全部生产门禁已经通过。

## 5. 发布安全规则

- 不给上游构建测试或 PR 工作流提供生产发布凭据。
- 不使用 `pull_request_target` 执行不可信源码，Actions 固定提交。
- 不手改 JSON/摘要伪造验证、不忽略失败、不绕过 GitHub secret scanning。
- 公开 CI 只输出精确白名单元数据；完整安装包发布必须有独立签收。
- 版本正式化不自动升级用户实例、不安装常驻服务、不清除数据和历史失败记录。
