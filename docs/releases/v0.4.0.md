# CLIProxyAPIPlus v0.4.0

发布日期：**2026-11-06（Asia/Shanghai）**。这是首个使用正式版本号的**源码发行**，GitHub Release 不标记为预发布。

## 发行内容

- 整合 CLIProxyAPI 核心、CPA-Manager-Plus 管理后端及原 React 前端，共用一个业务进程和业务端口。
- 管理页直接检查两个上游正式版本，管理员确认后执行隔离源码构建、验证、安装及程序/数据成对回滚，不需要额外发行服务。
- 完整 Portable 构建配方支持内置 Python/Go/Node/npm、匹配源码配方、共享文件日志、用量及模型价格配置。
- README、详细使用/开发文档和兼容模式说明统一至 0.4.0，程序版本元数据按构建版本报告 release / development 等通道，而非永久硬编码预发布状态。

## 下载与构建

本次 Release 提供 GitHub 生成的源码归档及脱敏验证元数据，**没有二进制安装包附件**。源码归档不是 Portable 安装包，不含原始上游快照、用户数据或内置 SDK。

```powershell
git clone --branch v0.4.0 --depth 1 https://github.com/EmrysCheng/CLIProxyAPIPlus.git
cd CLIProxyAPIPlus
python scripts/hydrate_upstreams.py
python scripts/project.py prepare
python scripts/project.py build
```

构建需要 Python 3.12+、Go 1.26.10、Node.js 24/npm 及可访问的依赖网络；完整产物位于 `dist/`。工具/依赖和完整包说明见[开发指南](../DEVELOPMENT_CN.md)。

## 安装与升级注意

- 构建后首次安装才执行 `--init`；已有配置/data 不要再次初始化。
- 保留完整安装包中的 `build-tools/`、`update-tools.json`、`updater-source/`，不只替换 EXE，不混用源码配方。
- 默认页面更新使用 `--web-updates --source-updates`，不配置 release-index；独立 Portable 不与外部自动拉起混用。
- 回滚恢复匹配的数据快照，不合并快照后的新增用量、配置或业务数据；升级前先做独立备份。
- 不自动改变任何已有运行安装、配置、数据或供应商账户。
